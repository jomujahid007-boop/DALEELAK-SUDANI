# دليلك السوداني — الواجهة والخدمات

## البنية المعتمدة

الموقع ولوحة الإدارة كلاهما مستضافان على **GitHub Pages**. Google Apps Script يعمل كواجهة API خلفية فقط لمعالجة الطلبات والاتصال بجدول Google Sheets؛ لا يقدّم صفحات HTML للمستخدم ولا يجب فتح رابط Apps Script للتنقل إلى الإدارة.

- `index.html`: واجهة التطبيق العامة.
- `admin.html`: لوحة الإدارة المستضافة على GitHub Pages.
- `Code.gs`: واجهة API الخلفية في Google Apps Script.
- `service-worker.js`: تحديث وتخزين ملفات واجهة التطبيق.
- `Admin.html` (بحرف A كبير): ملف قديم لواجهة Apps Script المباشرة، وليس صفحة الإدارة المستخدمة في الموقع الحالي.

## الروابط

- الموقع: https://jomujahid007-boop.github.io/DALEELAK-SUDANI/
- لوحة الإدارة: https://jomujahid007-boop.github.io/DALEELAK-SUDANI/admin.html
- رابط Apps Script المنشور يستخدم للاتصال البرمجي فقط.

## إعداد أو تحديث الخادم الخلفي

1. افتح مشروع Apps Script المرتبط بقاعدة بيانات دليلك.
2. حدّث ملف `Code.gs` بمحتوى الملف الموجود في هذا المستودع إذا تغيّر الكود.
3. من **Deploy → Manage deployments** عدّل النشر الحالي، واختر **New version** ثم **Deploy**.
4. حافظ على صلاحية الوصول المطلوبة للتطبيق (**Anyone**) والتنفيذ (**Me**) كما هي في إعداد النشر الحالي.
5. انسخ رابط النشر الجديد إلى ثابت `API_URL` في كل من `index.html` و`admin.html` إذا تغيّر الرابط.
6. لا تنفّذ `setupDatabase` مرة أخرى، ولا تحذف أوراق Google Sheets أو تعِد تهيئتها.
7. لا تحتاج إلى إنشاء صفحة إدارة داخل Apps Script أو إضافة `?page=admin` إلى رابط الخادم.

## نشر واجهة GitHub Pages

1. ادفع ملفات الواجهة إلى الفرع `main`.
2. تأكد أن **Settings → Pages** مضبوط على الفرع `main` والمجلد `/ (root)`.
3. انتظر اكتمال نشر GitHub Pages.
4. افتح رابط الموقع أو رابط الإدارة أعلاه. من زر «الإدارة» داخل التطبيق يجب الانتقال إلى `admin.html` على GitHub Pages.

## طريقة الاتصال

- تحميل البيانات العامة يتم بطلب JSONP إلى Apps Script.
- العمليات التي تتضمن بيانات حساسة، مثل كلمة مرور الإدارة ورمز الجلسة، تُرسل في جسم POST ولا توضع في عنوان URL.
- نتيجة كل POST تُسترجع باستخدام معرّف طلب عشوائي عبر JSONP مؤقت.
- واجهة الإدارة لا تستخدم `google.script.run` ولا تعتمد على فتح صفحة Apps Script داخل Safari.
- لا تضع كلمة مرور الإدارة أو رموز الجلسات أو بيانات سرية في ملفات GitHub.

## اختبار ما بعد النشر

- افتح الموقع ولوحة الإدارة على الكمبيوتر وعلى Safari في الجوال.
- تأكد أن عنوان لوحة الإدارة يبدأ بـ `https://jomujahid007-boop.github.io/` وليس `script.google.com`.
- جرّب تسجيل دخول الإدارة وتأكد من ظهور الطلبات.
- اختبر تحديث الطلبات والرفض والحذف على إعلان تجريبي فقط.
- لا تؤكد دفعاً إلا بعد مطابقة رقم العملية والتحقق من وصول مبلغ 20 ريال فعلياً.
- أرسل طلب إعلان تجريبياً وتأكد من وصوله إلى ورقة `Providers` بحالة `Pending`.

## ملاحظات أمان وتشغيل

- Apps Script يظل ضرورياً كخادم خلفي؛ استضافة الواجهة على GitHub لا تعني الاستغناء عن الخادم أو قاعدة البيانات.
- إجراءات تحديد معدل إرسال الإعلانات وفحص إثبات الدفع والتحقق من ملفات الصور موجودة في الخادم. لا تعتبر هذه الإجراءات ضماناً مطلقاً ضد الإساءة.
- لا تنشر بيانات الدخول أو روابط داخلية أو محتوى Script Properties في المستودع.
