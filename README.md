# دليلك السوداني — GitHub Pages Frontend

هذه النسخة تنقل واجهة الموقع إلى GitHub Pages، مع إبقاء Google Sheets وGoogle Apps Script كقاعدة بيانات وخادم خلفي. لا تنفّذ `setupDatabase` مرة أخرى؛ قاعدة البيانات الحالية تبقى كما هي.

## الملفات
- `index.html`: واجهة الموقع العامة ولوحة الإدارة.
- `Code.gs`: كود Google Apps Script الخلفي، ويحتوي على جسر API عبر `doPost`.

## إعداد الخادم الخلفي (مرة واحدة بعد تحديث الكود)
1. افتح مشروع Google Apps Script المرتبط بجدول بيانات دليلك السوداني.
2. استبدل محتوى ملف `Code.gs` بالكامل بمحتوى ملف `Code.gs` الموجود هنا.
3. لا تغيّر خصائص المشروع السرية، ولا تحذف أوراق Google Sheets.
4. من **Deploy → Manage deployments** اضغط تعديل (رمز القلم) على النشر الحالي.
5. اختر **New version** ثم **Deploy**. حافظ على صلاحية الوصول الحالية **Anyone** والتنفيذ **Me**.
6. تأكد أن رابط النشر ما زال هو الرابط الموجود في أعلى ملف `index.html` داخل `DALEELAK_API_URL`.

## تفعيل GitHub Pages
1. افتح إعدادات المستودع **Settings → Pages**.
2. في **Build and deployment** اختر **Deploy from a branch**.
3. اختر الفرع `main` والمجلد `/ (root)` ثم **Save**.
4. انتظر ظهور رابط الموقع: `https://jomujahid007-boop.github.io/DALEELAK-SUDANI/`.

## اختبار ما بعد النشر
- افتح رابط GitHub Pages على الكمبيوتر والهاتف.
- تأكد من ظهور الأقسام والإعلانات المعتمدة.
- أرسل طلباً تجريبياً وتأكد من وصوله إلى ورقة `Providers` بحالة `Pending`.
- اختبر تسجيل دخول الإدارة، مراجعة الطلب، ثم تأكيد الدفع ونشر الإعلان.
- لا تؤكد عملية دفع إلا بعد مطابقة رقم العملية ووصول مبلغ 20 ريال فعلياً.

## ملاحظات أمان
- كلمة مرور الإدارة لا توضع في GitHub؛ تبقى في Script Properties.
- رمز جلسة الإدارة لا يوضع في عنوان URL، ويُرسل ضمن طلب POST.
- `doPost` يرسل نتيجة الطلب إلى iframe الذي أنشأه الموقع، ويقيد `postMessage` إلى أصل GitHub Pages المحدد في `Code.gs`.
- لا تشارك رابط النشر مع أي طرف غير موثوق إذا كانت هناك حاجة لتقييد الوصول لاحقاً.

## تحسينات الحماية الحالية
- حدّ الخادم عدد طلبات الإعلان إلى 3 طلبات في الساعة و6 طلبات خلال 24 ساعة لكل رقم تواصل، مع فحص حقل honeypot والحد الأدنى لمدة تعبئة النموذج.
- يتحقق الخادم من أن القسم المختار مفعّل، ولا يقبل نشر طلب جديد إلا بعد تسجيل إثبات الدفع ومراجعته إدارياً.
- يمنع تكرار رقم العملية بعد تطبيعه، ويتحقق من قيمة الرسوم وطريقة الدفع وحالة الطلب قبل النشر.
- يتحقق من توقيع ملفات الصور الفعلي (JPEG/PNG/WEBP)، ويحدّ حجمها وعددها، ويحاول تنظيف الملفات إذا فشل حفظ الإعلان.
- تمت ترقية تخزين كلمة مرور الإدارة إلى PBKDF2-HMAC-SHA256 مع 120,000 دورة. الحسابات القديمة تُرقّى تلقائياً بعد أول تسجيل دخول صحيح، دون تغيير كلمة المرور.
- يتحقق المتصفح من أن رد API جاء من iframe الخاص بالطلب نفسه.

## حدود الحماية قبل الإطلاق العام
هذه الإجراءات تقلل إساءة الاستخدام لكنها لا تضمن انعدام الثغرات أو تمنع كل الروبوتات. تطبيق Apps Script الحالي لا يوفّر عنوان IP للطلب داخل هذا الكود، لذلك تحديد المعدل هنا مرتبط برقم التواصل ويمكن تجاوزه بمجموعات أرقام مختلفة. قبل حملة عامة كبيرة، يوصى بإضافة تحدي CAPTCHA مثل Cloudflare Turnstile أو تمرير الطلبات عبر وسيط يطبق تحديد المعدل حسب IP. كما يجب اختبار النسخة المنشورة فعلياً على الجوال والكمبيوتر وإجراء طلب ودفع تجريبيين قبل الإعلان.
